5. Implementation Details and Modifications

This course advisor was developed for the Daytona State College BSIT program using HTML, CSS, JavaScript, and JSON.

Features and Modifications

  • Created a custom JSON dataset containing 15 courses.
  • Dynamically generated course checkboxes using JavaScript.
  • Implemented AND and OR prerequisite checking.
  • Disabled conflicting alternative course selections.
  • Added course details, prerequisite descriptions, and notes.
  • Added drag-and-drop course planning.
  • Added buttons for adding and removing courses.
  • Implemented automatic planned-credit calculations.
  • Added automatic eligibility updates when selections change.
  • Designed a responsive interface for desktop and mobile.

This project is a demonstration using a subset of courses. Students should verify requirements with the official catalog.
