HTML5 Canvas Spirograph

This program uses HTML5 Canvas and JavaScript to create a Spirograph pattern.

Enter values for the outer radius (R), inner radius (r), and pen offset (O), then select Start Drawing.

x = (R + r) cos(t) − (r + O) cos(((R + r) / r)t)

y = (R + r) sin(t) − (r + O) sin(((R + r) / r)t)

Spirograph Settings

Drawing Values Enter a value between 50 and 200. Enter a value between 10 and 150. The inner radius cannot be greater than R. Enter a value from 0 up to the inner radius.
